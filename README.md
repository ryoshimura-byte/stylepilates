# Style Pilates 経営チーム

ピラティススタジオ「Style Pilates」の**会社全体の経営**を回すための組織リポジトリです。
経理・財務・マーケティング・経営の4部署を定義し、それぞれを Claude Code のサブエージェント
（＝実務を任せられる担当者）として呼び出せるようにしています。

## 組織図

```
                    ┌─────────────────────┐
                    │   経営（CEO / 経営企画）  │
                    │  全社戦略・意思決定・統括   │
                    └──────────┬──────────┘
                               │
         ┌─────────────────────┼─────────────────────┐
         │                     │                     │
   ┌─────┴─────┐         ┌─────┴─────┐         ┌─────┴─────┐
   │   経理部    │         │   財務部    │         │ マーケティング部 │
   │ 記帳・月次決算 │         │ 資金繰り・投資 │         │ 集客・ブランド  │
   │ 税務・請求   │         │ 融資・資本政策 │         │ 会員継続・CRM  │
   └───────────┘         └───────────┘         └───────────┘
        （過去を正しく記録）      （未来のお金を作る）      （売上をつくる）
```

## 部署一覧

| 部署 | エージェント名 | 一言でいうと | 詳細ドキュメント |
|---|---|---|---|
| 経営 | `keiei` | 全社の意思決定と部署間の調整 | [docs/org/keiei.md](docs/org/keiei.md) |
| 経理 | `keiri` | 数字を正しく記録し、月次決算を締める | [docs/org/keiri.md](docs/org/keiri.md) |
| 財務 | `zaimu` | 資金繰り・融資・投資判断 | [docs/org/zaimu.md](docs/org/zaimu.md) |
| マーケティング | `marketing` | 新規集客と会員継続 | [docs/org/marketing.md](docs/org/marketing.md) |

## 使い方

Claude Code で部署を名指しして依頼します。

```
経理部に今月の月次決算を締めてもらって
zaimu に来期の資金繰り表をレビューさせて
マーケ部に今月の集客レポートを作らせて
```

全社横断の相談（例：「スタジオをもう1店舗出すべきか」）は **経営（keiei）** に投げてください。
経営が論点を分解し、必要に応じて経理・財務・マーケの各部署を招集します。

## 経営サイクル（月次）

| 時期 | 動き | 主担当 |
|---|---|---|
| 月初 1–5営業日 | 前月の月次決算を締める | 経理 |
| 月初 5–7営業日 | 資金繰り表を更新、着地見込みを更新 | 財務 |
| 月初 5–7営業日 | 前月の集客・継続レポート | マーケティング |
| 月初 第2週 | 月次経営会議（実績レビュー＋打ち手決定） | 経営 |
| 月中 | 決定した打ち手の実行・進捗確認 | 各部署 |
| 月末 | 翌月の予算・シフト・キャンペーン確定 | 経営＋各部署 |
