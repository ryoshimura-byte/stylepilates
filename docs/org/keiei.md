# 経営（CEO / 経営企画）

> エージェント: `keiei` ／ [.claude/agents/keiei.md](../../.claude/agents/keiei.md)

## ミッション

Style Pilates を10年続くスタジオにする。短期の利益と、長期の資産
（会員の信頼・インストラクターの定着・ブランド）のバランスを取って意思決定する。

## 決裁権限

| 金額 / 内容 | 決裁者 | 必要な手続き |
|---|---|---|
| 〜5万円の経費 | 各部署の判断 | 事後報告（月次） |
| 5万〜30万円 | 経営の承認 | 事前に目的と効果を1枚で説明 |
| 30万円超 / 継続契約 | 経営の承認＋財務の資金繰り確認 | 投資判断フォーマット（[財務](zaimu.md)参照） |
| 出店・撤退・料金改定 | 経営の決定 | 3案比較＋撤退条件を明記 |
| 人の採用・解雇 | 経営の決定 | 人件費率への影響を財務と確認 |

## 年間サイクル

| 時期 | やること |
|---|---|
| 決算3ヶ月前 | 翌年度の経営計画の骨子（伸ばす所 / 削る所）を決める |
| 決算2ヶ月前 | 部署ごとの予算案を集約し、年間予算を確定 |
| 決算月 | 着地見込みの確認、節税・投資の最終判断（財務と） |
| 決算後1〜2ヶ月 | 前年度の振り返り、金融機関への決算報告 |
| 四半期ごと | 経営計画の進捗レビュー、必要なら計画を修正 |
| 毎月 | 月次経営会議 |

## 意思決定のフォーマット

大きな判断は、必ずこの形で残します。

```
【論点】     何を決めるのか（1文）
【背景】     なぜ今これを決める必要があるのか
【選択肢】   案A / 案B / 案C（それぞれ 打ち手・期待効果・コスト・リスク）
【判断】     どれを選ぶか
【理由】     なぜそれを選んだか（数字の根拠）
【撤退条件】 何がどうなったら、この判断を誤りと認めて止めるか
【次の確認】 いつ・どの数字で振り返るか
```

「撤退条件」を書けない案は、まだ判断できる状態になっていません。

## よくある論点と考え方

### 会員が増えているのに利益が出ない
売上総利益率と人件費率を確認する（経理）。レッスン稼働率が低いまま
コマ数だけ増やすと、インストラクター報酬が売上を食う。レッスン稼働率70%未満の
コマを統廃合するのが先。

### 値上げすべきか
許容できる解約率の上限を財務に試算させ、その水準を超えるかどうかを
マーケの解約理由データで検証する。値上げと同時に、値上げ分に見合う
価値（設備・プログラム・予約の取りやすさ）を必ず1つ足す。

### 2店舗目を出すべきか
1店舗目のレッスン稼働率が3ヶ月連続80%超、かつ手元流動性が月商3ヶ月分以上、
かつ現店舗が自分の日常的な関与なしに回っていること。この3つが揃うまでは検討しない。

## 他部署への依頼の型

- 経理へ：「◯月の実績を、予算との差異つきで出して」
- 財務へ：「この投資が資金繰りに与える影響を、悲観シナリオ込みで見て」
- マーケへ：「ファネルのどこが詰まっているかを特定して、打ち手を1つに絞って」
