# マーケティング部

> エージェント: `marketing` ／ [.claude/agents/marketing.md](../../.claude/agents/marketing.md)

## ミッション

新しい会員に出会い、長く通ってもらう。
売上 = 会員数 × 単価 × 継続月数。**継続は新規獲得と同格の仕事**として扱う。

## ファネル管理

```
   認知 ──→ 体験予約 ──→ 体験来店 ──→ 入会 ──→ 継続 ──→ 紹介
         予約率      来店率       入会率    継続率   紹介率
```

毎月、各段階の数字を出し、**最も詰まっている1箇所**を特定してから施策を打ちます。

| 段階 | 主な指標 | 目安 | 詰まっている時の打ち手 |
|---|---|---|---|
| 認知 | インプレッション、検索順位 | — | Googleビジネスプロフィール整備、SNS投稿頻度、口コミ獲得 |
| 体験予約 | 予約数、CPA | — | LPの改善、予約導線の短縮、広告クリエイティブの差し替え |
| 体験来店 | 来店率 | 85%以上 | 前日リマインド（LINE）、予約から来店までの日数を短縮 |
| 入会 | 入会率 | 50%以上 | 体験時のカウンセリング改善、当日入会特典、料金説明の明確化 |
| 継続 | 月次解約率 | 5%未満 | 初回30日の体験設計、来店頻度が落ちた会員へのフォロー |
| 紹介 | 紹介経由入会比率 | 20%以上 | 紹介制度の設計、紹介したくなるタイミングの見極め |

## リテンション（継続）の考え方

新規1人を獲得するコストは、既存1人を維持するコストの数倍です。
にもかかわらず、多くのスタジオは広告にだけお金を使います。

### 最初の30日が全て
入会後30日の来店回数が、その後の継続率をほぼ決めます。
入会直後の会員には次を必ず実施します。

1. 入会当日に、次回・次々回の予約を確定させる
2. 1週間以内に3回来てもらう導線（初月集中プログラム等）
3. 2週目にインストラクターから個別フィードバック
4. 30日目に体の変化を可視化（写真・可動域・姿勢の記録）

### 解約の予兆を検知する
解約は突然起きません。**来店頻度の低下が先行**します。

| 予兆 | アクション |
|---|---|
| 月2回未満が2ヶ月連続 | 個別に連絡し、通いやすい時間帯を再提案 |
| 予約キャンセルが3回連続 | 障壁（時間・体調・満足度）をヒアリング |
| 3週間以上来店なし | 休会オプションを提示（解約より休会の方がまだ戻ってくる） |

### 解約理由の分類
必ず次の5分類で記録し、「防げた解約」だけを対策の対象にします。

1. 料金（高い / 使いこなせていない）
2. 時間が合わない（スケジュール・立地）
3. 効果を感じない
4. 不可抗力（引越し・妊娠・怪我・転職）
5. 人間関係・雰囲気

## キャンペーン設計のルール

企画時に、必ずこの4点を先に決めます。

```
【目的】      ファネルのどの段階を改善するのか（1箇所だけ）
【目標】      具体的な数値目標（例：体験予約 30件、入会 15件）
【期間】      開始日と終了日（延長は原則しない）
【撤退ライン】いつまでに何が達成されなければ止めるか
```

**値引きは最後の手段。** 割引で集めた会員は継続率が明確に低くなります。
値引きの前に、体験の質・予約のしやすさ・初回30日の設計を先に改善します。
どうしても値引きするなら、月会費の割引ではなく**入会金の減免**（1回限りのコスト）を選びます。

## 広告予算の考え方

- 予算の上限は財務部から受け取る
- CAC（1入会あたりの獲得コスト）が **LTV の 1/3** を超えるチャネルは、
  単価を上げるか、止める
- チャネルごとに CAC を分けて計測する。合算の CAC は改善の役に立たない
- 紹介は CAC が最も低く継続率が最も高い。ここへの投資を最優先する

## レッスンスケジュールの需要分析

稼働率の低い時間帯は、売上を生まずにインストラクター報酬だけを消費します。

- 時間帯 × 曜日 × プログラム別の稼働率を毎月出す
- 稼働率50%未満のコマは、統合・時間変更・プログラム変更を提案する
- 逆に稼働率95%超のコマは機会損失。同時間帯の増設を経営に提案する

## 表現のルール（守ること）

- 「必ず痩せる」「◯kg減を保証」等、効果を断定・保証する表現は使わない
- 医療行為・治療効果を示唆する表現は使わない（ピラティスは医療ではない）
- ビフォーアフター写真は、本人の書面同意を得たもののみ使用する
- レビューの自作自演、対価と引き換えの★評価依頼はしない
- 「解約はいつでも可能」等の条件は、実際の規約と一致させる
