# 財務部

> エージェント: `zaimu` ／ [.claude/agents/zaimu.md](../../.claude/agents/zaimu.md)

## ミッション

会社の現金を切らさないこと。そして成長のための資金を最適なコストで用意すること。

経理が「過去を正しく記録する」なら、財務は「未来のお金を作り、守る」。
役割が違うので、同じ数字を見ても結論が違ってよい。

## 資金繰り表

### 13週資金繰り（週次更新）
直近13週の入出金を週単位で並べ、週末残高の推移を追います。
ショートの兆候は月次では見えず、週次で初めて見えます。

### 12ヶ月資金繰り（月次更新）
月初に経理から確定実績を受け取ってから更新。次を必ず明示します。

- 12ヶ月中の**最低残高月**とその金額
- その金額が**月商の何ヶ月分**か
- 月商3ヶ月分を割り込む場合の、対応案（支出の後ろ倒し / 融資 / 施策の縮小）

### 予測の置き方

| 項目 | 置き方 |
|---|---|
| 月会費収入 | 現会員数 × 単価 × (1 − 想定解約率)。解約率は直近3ヶ月の実績値を使う |
| 新規入会 | マーケの目標値ではなく、直近3ヶ月の実績平均。良い月を基準にしない |
| 都度・パーソナル | 直近3ヶ月の平均。季節性（夏・年末年始の落ち込み）を反映 |
| 固定費 | 契約書ベースの確定値 |
| 変動費 | 売上連動分は売上予測に連動させる |
| 賞与・税金・更新料 | 発生月にまとめて計上（忘れやすい最大の落とし穴） |

## 投資判断フォーマット

30万円超の支出・継続契約は、このフォーマットで経営に上げます。

```
【投資案件】
初期投資額      ：
月次の増加収入  ：（根拠となる稼働率・単価を明記）
月次の増加費用  ：
月次の増加利益  ：
単純回収期間    ：
資金繰りへの影響：最低残高が ¥ → ¥（月商 . ヶ月分）
前提が崩れる条件：
撤退条件        ：
推奨            ：実行 / 条件付き実行 / 見送り（理由）
```

**回収期間の目安**：マシン等の設備は36ヶ月以内、内装は60ヶ月以内、
広告等の販促は12ヶ月以内。これを超える案件は、慎重に扱います。

## 資金調達

| 手段 | 使いどころ | 注意点 |
|---|---|---|
| 日本政策金融公庫 | 創業・設備投資 | 金利が低い。決算書と事業計画が要る |
| 信用金庫・地銀のプロパー融資 | 運転資金・設備 | 平時から取引と報告を続けておくこと |
| 信用保証協会付き融資 | 実績が浅い時期 | 保証料が上乗せされる |
| リース | マシン導入 | 初期負担は軽いが総支払額は増える |
| 補助金・助成金 | 設備投資・雇用 | 原則**後払い**。一時的に自己資金が必要 |

**融資は必要になる前に相談する。** 資金が減ってから駆け込むと条件が悪くなります。
決算書ができたら、借入がなくても金融機関に持参して関係を作っておきます。

## 早期警告のトリガー

以下に該当した時点で、実際に問題が起きる前に経営へ報告します。

| トリガー | 意味 |
|---|---|
| 13週先の最低残高が月商1.5ヶ月分を下回る見込み | 短期の資金ショート予兆 |
| 12ヶ月先の最低残高が月商3ヶ月分を下回る見込み | 中期の資金不足 |
| 営業キャッシュフローが2ヶ月連続でマイナス | 本業でお金が減っている |
| 前受金が3ヶ月連続で減少 | 将来の収入が細っている |
| 借入金月商倍率が6ヶ月分を超える | 借入依存が高い |

## 価格改定シミュレーション

値上げ判断は、必ず3シナリオで出します。

| シナリオ | 値上げによる追加解約 | 会員数 | 月商 | 判定 |
|---|---|---|---|---|
| 楽観 | +1pt | | | |
| 標準 | +3pt | | | |
| 悲観 | +6pt | | | |

そのうえで **「解約率が何ptまで悪化しても値上げ前の月商を維持できるか」** = 損益分岐解約率
を算出し、マーケの解約理由データと突き合わせて実現可能性を判断します。
