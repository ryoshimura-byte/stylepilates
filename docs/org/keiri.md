# 経理部

> エージェント: `keiri` ／ [.claude/agents/keiri.md](../../.claude/agents/keiri.md)

## ミッション

会社で起きたことを、正確に・期限内に・同じルールで数字にする。
経理の数字は全ての経営判断の土台であり、精度と期限の両方が求められる。

## 業務カレンダー

### 日次
- 売上の記録（月会費・都度払い・回数券消化・パーソナル・物販）
- 現金残高と、カード・電子決済・予約システムの入金データの照合
- 領収書・請求書の受領と保管

### 週次
- 入金消込（未入金の会員・法人をリストアップ）
- 経費精算の処理
- 支払予定の確認（財務へ共有）

### 月次（前月分を当月5営業日以内）
[月次決算チェックリスト](../templates/month-end-close-checklist.md) を実施し、
損益計算書・増減理由・未収金/前受金残高の3点セットを経営へ提出。

### 年次
- 決算資料の作成、顧問税理士への連携
- 法人税・消費税・償却資産税の申告サポート
- 年末調整、法定調書
- 棚卸（物販在庫）

## 収益認識ルール

ピラティススタジオ特有の論点です。ここを間違えると、月次の売上が実態とズレます。

| 商品 | 入金タイミング | 売上計上タイミング |
|---|---|---|
| 月会費（当月分） | 当月引落 | 当月 |
| 月会費（翌月分を前月徴収） | 前月引落 | 翌月（徴収時は**前受金**） |
| 回数券（10回券など） | 購入時に一括 | **1回消化ごとに1/10ずつ**（未消化分は前受金） |
| ドロップイン | 都度 | 当日 |
| パーソナル | 都度 or 事前 | セッション実施日 |
| 物販 | 販売時 | 販売時 |
| 入会金 | 入会時 | 入会時 |

**回数券の未消化残高（前受金）は必ず毎月末に残高を出すこと。**
これは「まだ提供していないサービスの預り金」であり、利益ではありません。
残高が膨らんでいる場合、将来の無償提供義務が積み上がっているサインです。

## 経理が出す3点セット（月次）

1. **損益計算書** — 当月 / 前月 / 前年同月 / 予算 の4列比較
2. **増減理由** — 前月比 ±20% を超えた科目には必ずコメント
3. **残高情報** — 未収金（滞留日数別）と前受金（月会費前受 / 回数券未消化）

## 内部統制の最低ライン

小規模事業者でも、これだけは守ります。

- 現金の出納記録と実残高を毎日照合する（差異は当日中に原因を特定）
- 支払いの承認者と実行者を可能な範囲で分ける
- 証憑のない支出は計上しない（仮払いで保留し、経営に報告）
- 銀行口座の残高を、通帳・ネットバンキングで週次確認
- 会員データ（氏名・連絡先・決済情報）は必要最小限の担当者のみアクセス可能にする

## 経理から見た危険信号

これらを見つけたら、待たずに経営へ報告します。

- 売上は横ばいなのに前受金が減り続けている → 会員が減っている先行サイン
- 未収金の30日超滞留が増えている → 決済失敗の放置、または督促の仕組み不全
- インストラクター報酬が売上を上回る勢いで伸びている → 低稼働のコマが増えている
- 現金差異が2ヶ月連続で発生している → 運用ルールの破綻
