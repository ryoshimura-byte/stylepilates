# KPI定義集

全部署が**同じ定義**で数字を語るための辞書です。
「マーケの売上」と「経理の売上」がズレる原因のほとんどは、定義の不一致です。
数字を報告するときは、この定義に従っているかを確認してください。

定義を変更する場合は、経営の承認を得たうえで過去分も遡って組み替え、比較可能性を保ちます。

---

## 会員・顧客

### 会員数（月末在籍会員数）
月末時点で有効な月額会員契約を持つ人数。休会中の会員は**含めない**（別途「休会者数」で管理）。
回数券のみの利用者は会員数に含めない。

### 新規入会数
当月に月額会員契約を開始した人数。再入会（過去に退会した人の復帰）は
「新規」ではなく「復会」として分けて数える。

### 解約数
当月に月額会員契約を終了した人数。休会は解約に含めない。

### 月次解約率（チャーンレート）
```
解約率 = 当月の解約数 ÷ 前月末の会員数 × 100
```
**目安：5% 未満**。年率換算では約46%が入れ替わる計算になるため、
これを超えると新規獲得が追いつかなくなります。

### 会員数の純増
```
純増 = 新規入会数 + 復会数 − 解約数
```
毎月プラスであることが健全な成長の最低条件です。

### 平均継続月数
```
平均継続月数 = 1 ÷ 月次解約率
```
解約率5%なら平均20ヶ月。解約率10%なら平均10ヶ月です。

## 売上・単価

### 売上（経理定義）
発生主義。**サービスを提供した月**に計上します。
前受けの月会費・未消化の回数券は売上ではなく前受金（負債）です。
詳細は [経理部](../org/keiri.md) の収益認識ルールを参照。

### 会員単価（ARPU）
```
ARPU = 月間の会員関連売上 ÷ 月末在籍会員数
```
月会費・都度・パーソナル・物販のうち、会員が支払った分を分子に含めます。

### LTV（顧客生涯価値）
```
LTV = ARPU × 売上総利益率 × 平均継続月数
```
粗利ベースで計算します。売上ベースの LTV は CAC との比較に使うと過大評価になります。

## 集客・獲得

### 体験予約数
当月に体験レッスンの予約が**入った**件数（実施日ではなく予約発生日でカウント）。

### 体験来店率
```
来店率 = 体験の実施数 ÷ 体験の予約数（当月実施予定分）× 100
```
**目安：85% 以上**。No-show（無断キャンセル）の裏返しの指標です。

### 体験 → 入会転換率
```
入会率 = 体験からの入会数 ÷ 体験の実施数 × 100
```
**目安：50% 以上**。体験当日の入会だけでなく、体験後30日以内の入会を含めます。

### CAC（顧客獲得単価）
```
CAC = 当月の獲得関連費用 ÷ 当月の新規入会数
```
分子には広告費に加え、**制作費・紹介キャンペーンの原資・体験レッスンの原価**を含めます。
広告費のみで計算した CAC は過小評価になります。チャネル別に分けて算出すること。

### LTV / CAC
**目安：3倍以上**。1倍を割ると、会員を集めるほど損をしている状態です。

## 稼働・オペレーション

> **「稼働率」は2種類あります。単に「稼働率」と呼ばないこと。**
> 座席が埋まっているか（レッスン稼働率）と、シフトに入った枠が実施されたか（シフト稼働率）は
> 別の指標です。同じ名前で呼ぶと、需要の話と人の稼働の話が混ざります。

### レッスン稼働率（座席充足）
```
レッスン稼働率 = 実際の参加者数 ÷ (開催コマ数 × 1コマの定員) × 100
```
**目安：70% 以上**。中止したコマは分母から除きます。
時間帯 × 曜日 × プログラム別に分解して見ること。
**用途：** 需要の把握。コマの統廃合・増設の判断に使います（マーケティング・経営）。

### シフト稼働率（実施率）
```
シフト稼働率 = 実施レッスン数 ÷ シフト枠数 × 100
```
**目安：90%**。シフトに入れた枠がどれだけ実際に実施されたかを見ます。
差分はキャンセル・振替であり、**キャンセル理由の内訳把握とセットで見ること**。
**用途：** オペレーションの把握。個人別・店舗別に集計します。
**注意：** 人事評価の4軸KPI（量・顧客支持・質・役割）にシフト稼働率は含まれません。
評価に使うのは実施枠数であり、シフト稼働率をそのまま評価ランクに読み替えないこと。

### 会員1人あたり月間来店回数
```
来店頻度 = 当月の会員による来店延べ数 ÷ 月末在籍会員数
```
**目安：4回以上**。継続率の最も強い先行指標です。ここが落ちると翌々月に解約が増えます。

## 収益性

### 売上総利益率
```
売上総利益率 = (売上 − 売上原価) ÷ 売上 × 100
```
売上原価 = インストラクター報酬（レッスン担当分）＋ 物販仕入。**目安：60% 以上**。

### 人件費率
```
人件費率 = (給料手当 + 外注費 + 法定福利費 + 役員報酬) ÷ 売上高 × 100
```
**外注費（業務委託インストラクターへの支払い）と役員報酬を必ず含めます。**
当社はレッスンの半分以上を業務委託が担っており、外注費は給料手当を上回ります。
外注費を除いた「人件費率」は人件費の実態を表さないため、使いません。

科目は会計上の実額を使います（役員報酬は実額科目があればそちらを優先）。

| ライン | 水準 | 意味 |
|---|---|---|
| 正常 | 48% 未満 | 問題なし |
| 警戒 | 48% 以上 | 要因分解（売上側か費用側か・一時要因か）を実施 |
| 凍結 | 50% 超 | 新たな増額（新規の役割手当付与・昇給・賞与の積み増し・新インセンティブ追加）を止める |

**判定は単月ではなく直近3ヶ月移動平均で行います。** 閑散月は単月で跳ねるため、
単月の数字で凍結を発動させないこと。

**凍結＝「支出の伸びを止める」であり、既に支給中の基本給・手当・確定済みインセンティブは
止めません**（引き下げには不利益変更の手続きが必要になるため）。
解除は四半期ごとに判定し、3ヶ月移動平均が48%未満に戻れば解除します。

### 家賃比率
```
家賃比率 = (地代家賃 + 共益費) ÷ 売上 × 100
```
**目安：20% 以下**。固定費なので、売上が落ちた月に一気に効いてきます。

### 営業利益率
```
営業利益率 = 営業利益 ÷ 売上 × 100
```
**目安：15% 以上**。

### 損益分岐点売上高
```
損益分岐点売上高 = 固定費 ÷ 限界利益率
限界利益率 = (売上 − 変動費) ÷ 売上
```
「毎月最低いくら売れば赤字にならないか」。会員数に換算して全社で共有します。

## 資金

### 手元流動性（月商比）
```
手元流動性 = (現金 + 預金) ÷ 月商
```
**目安：3ヶ月分以上**。これが財務部の最重要指標です。

### 営業キャッシュフロー
本業の営業活動で増減した現金。継続してプラスであること。
利益が出ていてもマイナスになることがあり、その場合は前受金の減少か未収金の増加が原因です。

### 借入金月商倍率
```
借入金月商倍率 = 有利子負債 ÷ 月商
```
**目安：6ヶ月分以下**。

### 債務償還年数
```
債務償還年数 = 有利子負債 ÷ (営業利益 + 減価償却費)
```
**目安：10年以内**。借入を今の稼ぐ力で何年で返せるか。

### 前受金残高
翌月分の月会費前受け＋回数券の未消化分。
**まだ提供していないサービスの預り金**であり、利益ではありません。
会員数の増減と整合しているかを毎月確認します。
