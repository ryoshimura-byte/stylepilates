# Instagram 運用ルール

担当部署：マーケティング部（`marketing`）
アカウント：@style_pilates_official
※ SNS運用は「部署」ではなく「役割」です。役割手当の対象であり、担い手は役割認定で決まります。

---

## 0. 目的とターゲット

**2026年11月、Google広告を停止しInstagramに集客を切り替えました。** 広告のCPAが
6月9,732円→7月39,721円に急騰し、広告費を4倍にしても入会が12件のまま動かなかったためです。
Instagramは補助ではなく、新規集客の主経路です。

| | |
|---|---|
| 目的 | ①認知拡大 ②体験レッスンの予約 |
| ターゲット | 20〜40代の**男女**。京都市内および近郊 |
| 要注意 | **男性にも通いやすいスタジオだと伝えること** |

### 男性に届けるために

- 効くネタ：腰痛／肩こり／デスクワーク疲れ／睡眠の質／反り腰／股関節の硬さ／ゴルフ・ランニング
- 「くびれ」「美脚」「産後」を前面に出した回を続けない。男性が自分ごとにできなくなる
- 装飾をピンク系・花柄に寄せない。グレージュ＋明朝の路線は男女どちらにも効く
- 「女性専用」と誤解される表現を使わない

## 1. Instagramに2つの役割を持たせる

Instagramを新規集客だけの道具として使うと、半分しか使えていません。

| 役割 | 使う機能 | 狙う相手 |
|---|---|---|
| **新規集客** | リール・カルーセル（フィード投稿） | まだ会員でない人 |
| **継続・解約防止** | ストーリーズ | すでに通っている会員 |

**後者が重要です。** 解約の45%が入会3〜4ヶ月目に集中し、割引明け213契約のうち33%（70件）が定価移行せずに離脱しています。
来店頻度が落ちた会員は、解約の前にまず「スタジオのことを考えなくなる」段階を通ります。
ストーリーズは、その段階に接触できる数少ない手段です。

フィードで新規を集めながら、ストーリーズで既存会員をつなぎ止める。
**マーケティング部は継続を新規獲得と同格の仕事として扱う**ため、ストーリーズの更新を止めないでください。

## 2. 完全個室という条件が、運用を決める

スタイルピラティスは全レッスンが完全個室です。これはSNS運用に直接影響します。

### 有利な点

- **他の会員が映り込まない。** 撮影の許可取りが1人分で済み、顔出しなしの構図も作りやすい
- 空間を占有できるので、撮影の時間と角度を自由に取れる

### 不利な点

- **「賑わい」が撮れない。** 大人数のクラス写真で活気を見せる手が使えない
- **写真だけでは個室だと分からない。** 空間の写真は、見る人には「空いている時間に撮った普通のスタジオ」に見えます

### だから

**「完全個室」は必ず文字で書いてください。** キャプションの1行目、または画像内のテキストに入れます。
「プライベートな空間」「おひとりに寄り添う」では伝わりません。検索にもAIにも拾われません。

賑わいの代わりに見せるのは、**インストラクターの人柄**と**マシン（リフォーマー）**です。

## 3. コンテンツの柱

| # | 柱 | 目的 | 形式 | 枠 |
|---|---|---|---|---|
| 1 | **BODYNOTE**（体の仕組み） | 保存される＝リーチが伸びる。男性に届く | カルーセル | 水 |
| 2 | 家でできるピラティス | フォロワー外リーチ＝入口 | リール | 火・金 |
| 3 | 完全個室とマシン | 差別化＝来店理由 | リール・実演 | 月・木 |
| 4 | ウェア紹介（スタジオ撮影） | 購買意欲のある層 × 地域 | フィード | 日・土 |
| 5 | 会員の変化 | 説得力（**書面同意必須**） | カルーセル | 随時 |

**1のBODYNOTEを主軸にしてください。** 保存される投稿がリーチを伸ばし、結果として2〜5が見られます。
宣伝ばかりの投稿は保存されず、リーチが伸びず、宣伝としても機能しません。

### 投稿を2軸で点検する

ネタを決める前に、その投稿が次のどちらに当たるかを確認します。

- **京都に届くか** — スタジオは京都の実店舗です。全国に届いても売上になりません
- **お金を払う気がある人に届くか** — 「家でできる」だけだと、家でやって終わります

| 柱 | 京都 | 払う気 |
|---|:---:|:---:|
| BODYNOTE | ✗ | △ |
| 家でできるピラティス | ✗ | ✗ |
| 完全個室とマシン | ✗ | ○ |
| ウェア紹介（スタジオ撮影） | ○ | ○ |

**両方◯が週2本（日・土）を下回らないこと。** ウェア紹介は必ずスタジオ・マシンの上で撮り、
位置情報を付けます。内容ではなく撮影場所で地域性を担保する設計です。

ウェアを買う人は、すでに通っているか通いたい人です。購買意欲の信号としては最も強い枠になります。

★ 京都在住者の獲得は、Instagram だけに負わせないこと。実測では
[京都駅前店]ホームページ80人・Google Map 37人と、MEOとHPが地域の受け皿になっています。

## 4. 投稿頻度

**フィードは毎日。曜日ごとに担当と「型」を固定します。**

| 曜 | 担当 | 型（毎回同じ枠を埋める） | 形式 | 狙い |
|---|---|---|---|---|
| 日 | りほ | ウェア紹介（**スタジオ・マシンの上で撮影**） | フィード | 京都 × 購買意欲 |
| 月 | りほ | マシンだとどう変わるか（スタジオ撮影） | カルーセル／リール | 来店理由 |
| 火 | ほのか | 家でできるピラティス（顔メイン） | リール／カルーセル | 親近感・入口 |
| 水 | あみ | **BODYNOTE**（体の仕組み・なぜそうなるか） | カルーセル | 保存 → 新規・男性 |
| 木 | ほのか | 家でできること／スタジオでしかできないこと | 顔出しリール | 来店理由 |
| 金 | あみ | 1分「寝る前エクササイズ」（**悩み別**） | リール | フォロワー外リーチ |
| 土 | ほのか | ウェア紹介（**スタジオで撮影**） | フィード | 京都 × 購買意欲 |

| その他 | 頻度 | 備考 |
|---|---|---|
| ストーリーズ | 週2〜3回 | フィードが毎日になるため、無理に毎日やらない |
| ハイライト | 随時更新 | 「体験レッスン」「料金」「完全個室」「アクセス」は常設 |

### 2つの公式アカウントの運用

アカウント統合の機能はInstagramにありません。**共同投稿（Collab）で、制作1本を両方に載せます。**
1つの投稿が全アカウントのフィードとプロフィールに表示され、いいね・コメント・再生数が合算されます。

| | 共同投稿者に入れる |
|---|---|
| 毎回 | 京都駅前店の公式アカウント |
| その日だけ | 担当者の個人アカウント |

| | ブランド公式（本店） | 京都駅前店 |
|---|---|---|
| フィード投稿 | すべてここから投稿 | 共同投稿で自動的に載る |
| ストーリーズ | ブランド全体 | **店舗固有**（空き枠・スタッフ・アクセス） |
| 手をかける量 | 多い | 少ない |

**店舗ごとに独自の投稿を作らないこと。** 制作が2倍になり、毎日投稿が続きません。
グリッドの重複が気になる場合は、ストーリーズで差をつけます。

3号店が出たときも、店舗アカウントを1つ足して共同投稿に加えるだけにします。
**「ブランド1本＋店舗アカウントは補助」の構造を崩さないでください。**
店舗ごとに独自運用すると、3店舗目で制作が3倍になり破綻します。

★ 共同投稿者の上限人数は仕様変更が多いため、投稿画面で確認すること。
★ 共同投稿はフィードとリールのみ。ストーリーズでは使えません。

### 毎日投稿を続けるための前提

**毎日投稿で最も多い失敗は、3週目で落ちることです。** その日に作ってその日に出す運用では続きません。

- **曜日＝型を固定する。** 毎回ゼロから考えない。埋める枠が決まっていれば制作時間が半分以下になる
- **撮影はまとめ取り。** 月1回・半日で、リール4〜8本分を撮る
- **カルーセルはテンプレートを使い回す。** 文言の差し替えだけで出せる状態にする
- **1週間分を前の週に作り終える。** 当日制作をやめる

### 知識系4本のネタが重複しないように

水・月・木・金は放っておくと内容がかぶります。**答える問いで分けます。**

| | 水（BODYNOTE） | 月 | 木 | 金 |
|---|---|---|---|---|
| 担当 | あみ | りほ | ほのか | あみ |
| 答える問い | **なぜそうなるのか**（原因） | **どう動かすのか**（やり方） | **どこでやるのか**（場所） | **今夜、何をするか** |
| 形式 | 解説カルーセル | マシン実演 | 顔出しで対比 | 実演（1分） |
| 場所 | 問わない | スタジオ・マシン | 両方を並べる | ベッド・布団の上 |
| 締め | 「保存して読み返して」 | 「スタジオで詳しく」 | 「違いは体験で」 | 「保存して今夜やってみて」 |

**原因（水）→ やり方（月）→ どこでやるか（木）** の順に並びます。
金曜は入口なので、この流れとは独立させて構いません。

月初に、水・月・木の3本が同じテーマで重ならないかだけ擦り合わせてください。

### 連載「BODYNOTE」（水曜・あみ）

**体の仕組みを説明する連載です。** 単発のネタではなく、通し番号を振ったシリーズとして運用します。

| 項目 | 内容 |
|---|---|
| 担当 | あみ |
| 枠 | 毎週水曜 |
| 形式 | カルーセル |
| 答える問い | **なぜそうなるのか**（原因の説明。やり方は月曜の担当） |
| 狙い | 保存を貯める／男性に届かせる |

**この連載を置く理由は3つです。**

1. **男性に届く。** 「家でできる」「ウェア」は女性寄りで、男性向けの枠が1本もありませんでした
2. **保存が貯まる。** 知識系はストック型。LINE追加に効くのは保存数です
3. **GBPコラムに流用できる。** Googleビジネスプロフィールの週2回投稿に原稿をそのまま使えます。
   制作1本で Instagram ＋ GBP ＋ AI検索対策の3か所に効きます

★ **第4水曜は「京都で暮らす体」の回にします。** 坂・階段・自転車・観光で歩いた日・着物。
連載の形式を保ったまま、京都在住者への地域性を確保するための枠です。

#### 初回13本（2026年11月〜2027年1月）

```
 1. 反り腰はなぜ起きるのか
 2. 肩が内に入る本当の理由（スマホだけではない）
 3. 「体幹が弱い」の正体
 4. 京都で暮らす体 ①坂と階段          ← 第4水曜
 5. 呼吸が浅いと何が起きるか
 6. 左右差はどこから生まれるか
 7. 腰痛と股関節の関係
 8. 京都で暮らす体 ②自転車の多い街     ← 第4水曜
 9. 猫背を「背中」で直そうとして直らない理由
10. 骨盤の前傾・後傾とは何か
11. 肩こりの原因が肩にない場合
12. 京都で暮らす体 ③観光で歩いた日     ← 第4水曜
13. 「柔らかい」と「動かせる」は違う
```

1・2・3・7・10・11 は男性の検索ボリュームが大きいテーマです。男性向けはここに寄せます。

### 金曜「寝る前エクササイズ」は悩み別にする

形式はシリーズのまま、**テーマを悩み別に選びます**（腰痛・肩こり・反り腰・デスクワーク）。
部位や悩みで切ると男性にも届きます。フォロワー外に届く唯一の形式なので、ここは入口として維持します。

### 動画の共通ルール

- 縦型・テロップ入り
- 最初の1〜2秒で引きつける一言を置く（例：「寝つきが悪い人、これやって」）
- 位置情報をつける
- ハッシュタグに「京都 ピラティス」と最寄りエリア名を入れる
- 最後は保存を促すか、プロフィール（体験予約）へ誘導する

**Googleビジネスプロフィールのコラム（週2回）と同じネタを使い回してください。**
同じ内容をInstagram向けに書き直すだけなので、制作の手間が半分になります。

## 5. 追う数字

**フォロワー数は追いません。** 増えても会員が増えなければ意味がありません。

毎月、次の4つを記録します。

| 指標 | なぜ見るか |
|---|---|
| **フォロワー以外へのリーチ** | 認知拡大の唯一の指標。リールが主戦場 |
| **保存数** | リーチの先行指標。保存される投稿が伸びる |
| **プロフィールアクセス数** | 投稿 → 興味 の転換 |
| **Instagram経由の体験予約数** | 唯一の成果指標 |

補助的に、ストーリーズ閲覧率（既存会員がまだ見ているか。下がったら継続の危険信号）も見ます。

### 広告をやめた穴の大きさ

7月時点で広告は月12件の入会を生んでいました。逆算すると置き換えに必要な数は次のとおりです。

```
入会 12件 ÷ 入会率 47%   = 体験来店 約26件
体験来店 26件 ÷ 来店率 85% = 体験予約 約31件／月
```

**月31件の体験予約が広告の完全な代替ラインです。** 段階を置いて近づけます。

指標の定義は [KPI定義集](../kpi/kpi-definitions.md) に従います。
Instagram経由の入会数が分からないと CAC が出せません。**体験予約時に流入元を必ず記録してください。**

## 6. やってはいけないこと

- 「必ず痩せる」「○kg減を保証」など効果を断定・保証する表現
- 「治る」「改善します」など治療効果を示唆する表現（ピラティスは医療ではありません）
- 「京都No.1」「京都で一番」など根拠を示さない最上級表示
- 他店を名指しで比較・批判する
- 口コミの自作自演、対価と引き換えの★評価依頼
- 事業者が運営を伏せたまま第三者を装う投稿（ステマ規制。2023年10月〜）

### 会員が映る投稿

- **書面同意を取ってください。** 口頭の「いいですよ」では残りません
- 同意書には、使用する媒体・期間・退会後の扱いを明記する
- ビフォーアフター写真は、体型を加工しない
- 同意の撤回を申し出られたら、速やかに削除する

## 7. 役割分担が決まるまでの暫定運用

現在、SNS運用の役割は2名に同額で仮当てされており、チーフが確定していません。
確定を待って運用開始を遅らせる必要はありません。暫定で次のように回してください。

- **投稿の最終確認者を1人決める。** 2人で相談して出すと止まります
- 撮影・編集・投稿の担当をネタごとに分ける（例：リールは担当A、カルーセルは担当B）
- **作業がシフト内か外かを記録する。** シフト外での撮影・編集が常態化している場合、労働時間管理の論点になります（★社労士確認）

役割分担の確定は、半期評価の面談で実態を聞いてから行います。
詳細は [半期評価シート](../hr/evaluation-sheet.md) と [評価運用マニュアル](../hr/evaluation-operations.md) を参照してください。
