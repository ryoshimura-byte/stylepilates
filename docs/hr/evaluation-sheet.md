# 半期評価シート（様式）

> 本様式は「制度表（評価制度シート ③評価サイクル）」の
> 「KPI実績＋役割評価＋本人コメントを評価シート1枚にまとめる」を実体化した空欄テンプレートです。
> **適用範囲：正社員のみ。** 役員・業務委託は本制度の対象外（業務委託は労働者性リスクのため
> 人事評価そのものを行わず、契約更新時の取引条件見直しのみ）。
>
> ★ 印は未確定事項（社労士確認前提を含む）です。★を外すのは確定後に限ります。
> 本様式に個人名・個別報酬額を記入した状態のものは、リポジトリにコミットしません
> （[CLAUDE.md](../../CLAUDE.md) 機密情報ルール）。記入済みシートは人事保管領域で管理します。

## 3. ダイヤル条項の申告

> 育児・介護等のライフイベント時は、**量（枠数）のダイヤルを下げても等級・基本給は下げません**。
> 役割ダイヤルで貢献を続けることで報酬を維持できます。復帰後に量を戻せば元の稼ぎ筋に戻ります。
> 申告は年1回の評価面談で行います（随時相談も可）。★社労士確認前提。

| 項目 | 記入欄 |
|---|---|
| 今期、量ダイヤルを下げているか | **はい** ／ いいえ |
| 事由 | 産前産後休業 ／ 育児休業 ／ 育児短時間勤務 ／ 介護 ／ その他（`　　　`） |
| 適用期間 | `YYYY年MM月` 〜 `YYYY年MM月`（または「継続中」） |
| 次期の希望（ダイヤルを戻す／据え置く／さらに下げる） | |
| 復帰予定・復帰後の希望枠数 | |

**上記が「はい」の場合、本様式上で以下を担保します（評価者は必ずチェックすること）：**

- [ ] **2-1（量）の実績は、降格判定・等級引き下げの根拠として用いない**
- [ ] 量の低下を理由に総合評価を引き下げていない（7. 総合評価の根拠欄に、量を使っていない旨を明記した）
- [ ] 役割ダイヤル（2-4）での貢献を評価対象として確認した
- [ ] 本人に上記の取り扱いを説明し、本人が理解したことを確認した

|---|---|
| 等級判定 | **維持** ／ 昇格（L`　` → L`　`） ／ **要検討** ／ 判定保留 |
| 昇格の場合、充足した要件 | 役割チーフ就任：有 ／ 無　＋　実施90枠×3ヶ月平均 ／ 指名30件/月 ／ 担当継続率が全店平均以上（いずれか）★仮置き基準 |

> **役割手当と等級の分離（制度上の重要ルール）：**
> 役割を降りた場合、**役割手当が外れるのみ**で、等級・基本給とは連動させません。
> 等級の見直し（降格を含む）は**年1回の評価**でのみ行い、実施する場合は激変緩和措置を設けます。
> ★正式な規程・激変緩和の具体設計は社労士確認前提。

## 10. 異議申立てのご案内

評価結果に不服がある場合、**本シートの受領後2週間以内に、書面で異議を申し立てる**ことができます。

| 項目 | 内容 |
|---|---|

> 受領日を記録したうえで、確定後の正式手続きに引き継ぎます。

## 記入上の注意

1. **数字は必ずデータ源と対象期間をセットで書く。** 出所の書けない数字は書かない。
2. **取れていないデータを推定で埋めない。** 欠測は「欠測」と書く。
3. 本シートに**個別の金額（基本給・手当額・賞与額）は記入しない**。処遇額は給与台帳側で管理する。
4. 記入済みシートは人事保管領域で管理し、リポジトリにはコミットしない。
5. ★の付いた項目は未確定。★を外すのは、役員承認または社労士確認が完了した後に限る。
