# 役割軸 行動基準（マーケティング／顧客管理領域）

評価4軸のうち **「役割：ロール定義書に対する遂行評価」** に使う行動基準のうち、
**カスタマー担当（主担当）と顧客管理・CS役割**に関わる部分を定めます。

制度表「インセンティブ」シートは、割引明け離脱対策として
**「入会3ヶ月目（割引明け直前）のフォロー（声かけ・プラン提案）を役割・評価項目として明文化する」**
と定めていますが、その中身が存在しませんでした。**本書がその中身です。**

- 作成：マーケティング部
- 位置づけ：**ロール定義書（導入スケジュール No.6、担当：吉村さん）の下敷き**。本書は素案であり、確定は吉村さん／社労士
- 関連：[評価運用マニュアル](evaluation-operations.md)／[半期評価シート](evaluation-sheet.md)／
  [KPI測定仕様書](kpi-measurement-spec.md)／[KPI定義集](../kpi/kpi-definitions.md)

## 0. 適用時期についての重要な但し書き

> **本書の基準を 2026年9月評価に遡って適用することは推奨しません。**

## 1. 二重払い回避の建て付け（最初に読む）

制度表「インセンティブ」シートは、この整理を明示しています。

> フォロー実施は評価加点、成果＝定価移行は本インセンティブで自動的に報酬化＝二重払いなし

本書はこれを踏襲します。

```
┌─────────────────────────┐      ┌─────────────────────────┐
│ 行動（やったこと）           │      │ 成果（結果として起きたこと）   │
│                         │      │                         │
│ ・割引明けフォローの実施      │      │ ・定価移行した              │
│ ・プラン提案の実施           │  →   │ ・5ヶ月目を突破した          │
│ ・カルテの更新              │      │ ・12ヶ月継続した            │
│ ・予兆への対応              │      │                         │
└───────────┬─────────────┘      └───────────┬─────────────┘
            ↓                                  ↓
   【役割軸】行動評価で加点                 【質軸】＋【継続インセンティブ】
   → 評価係数・役割手当に反映              → 変動報酬として自動的に支払われる
```

### 守るべき2つのルール

| # | ルール | 理由 |
|---|---|---|
| **1** | **成果指標（定価移行率・5ヶ月目突破率・12ヶ月継続率）を、役割軸の採点に使わない** | 質軸と継続インセンティブで既に処遇されている。役割軸でも使うと同じ成果で三重に評価することになる |
| **2** | **行動指標（実施率）を、継続インセンティブの支給要件にしない** | 行動は評価係数で、成果は変動報酬で。入口を分けておくことで、どちらかが欠測しても片方は機能する |

### この建て付けの意味 ―― 「やったが成果が出なかった」をどう扱うか

> **行動基準を満たしていれば、成果が出なくても役割軸は満点で構いません。**

会員が退会するかどうかは、転居・妊娠・価格感応度・体調など、担当者の統制外の要因に大きく左右されます。
成果だけで評価すると、**運の良い担当会員を持った人が高評価になります。**
一方、行動は本人が決められます。だから行動で評価します。

成果の差は継続インセンティブ（変動報酬）が自動的に吸収します。
**行動を尽くしても成果が出なかった人は、変動報酬が少ないという形で既に差がついています。**
そこに役割軸でもう一度差をつけるのが「二重払い」ならぬ「二重罰」であり、これを避けます。

### 逆方向も同じ

「成果は出たが行動記録が無い」場合、継続インセンティブは支払われますが役割軸は加点されません。
再現性のある仕事になっていないためです。

## 2. 観察可能性の原則

> **記録に残っていないものは、遂行していないものとして扱います。**

冷たいルールに見えますが、これは評価される側を守るためのルールです。

- 記録が判定の根拠なら、**評価者が変わっても結果が変わりません。**
- 記録が無いと、判定は「よくやっている印象がある」になります。
  印象評価は、声が大きい人・評価者と接点が多い人が有利になります。
- 制度表が「評価者の恣意性排除」を継続課題（要対応4）としていることへの、実務側の回答です。

### 記録の場所は1箇所に決める

| 記録するもの | 記録先 |
|---|---|
| 会員への接触・提案・所感 | **Square の会員カルテ／メモ欄** ★システム上の記録先は要確定（吉村さん） |
| 担当変更の引き継ぎ | 同上（引き継ぎメモ） |
| 上申（値引き相談・離脱懸念） | 店舗責任者への連絡記録（★様式要確定） |

**記録先が複数あると、探せない記録は無い記録と同じになります。** 1箇所に統一します。

## 3. カスタマー担当（主担当）の職務行動基準

### 3-0. カスタマー担当とは

| 層 | 定義 | 誰が持つか |
|---|---|---|
| レッスン担当 | 実際にレッスンを提供する人 | 正社員・業務委託どちらも |
| **カスタマー担当（主担当）** | **会員の継続に責任を持つ人** | **正社員のみ** |

**カスタマー担当は、全正社員が基本職務として持ちます**（役割手当の対象ではありません）。
入会時に必ず1名が割り当てられ、委託が獲得した会員にも正社員のフォローが付く設計です。

> 「レッスンをした人」ではなく「継続を守る活動をした人」への責任・報酬、という制度の理屈に従います。

職務は次の4領域です。以下、それぞれについて **「何をしたら遂行したと言えるか」** を定めます。

---

### 3-1. 割引明けフォロー

#### 何をするか

**入会3ヶ月目（割引明け月の前月）に、担当会員全員に1回以上の個別接触を行う。**

#### なぜ3ヶ月目か

会員LTV分析シートの事実：

- **解約の45%が3〜4ヶ月目に集中**
- **割引明け213契約の33%（70件）が定価移行せず離脱**（定価移行率67%、目標75%）

接触が割引明けの**後**になると、会員にとっては「値上げの通知」です。
**前**なら「続け方の相談」になります。同じ内容でも、タイミングで意味が変わります。

#### 遂行したと言える条件

> **カルテに次の3点が記録されていること。**

| # | 記録項目 | 記入例 |
|---|---|---|
| a | **接触日** | 2026-10-12 |
| b | **接触手段** | `対面` / `LINE` / `電話` |
| c | **会員の反応区分** | `継続意向あり` / `不安あり`（＋内容） / `プラン変更希望` / `連絡不通` |

#### 判定の細則

| ケース | 遂行判定 |
|---|---|
| 対象会員に接触し、a〜c を記録した | **遂行** |
| **連絡不通（3回試行して繋がらない）** | **遂行**（試行の記録が3件あること） |
| 接触したが記録が無い | 未遂行（§2 の原則） |
| 接触したが反応区分が空欄 | 未遂行（何が起きたか読み取れないため） |
| 対象会員が3ヶ月目より前に退会した | **対象外**（分母から除く） |
| 対象会員が休会中 | 対象。休会中の会員こそ接触が要る |
| 期間中に担当が変わった | **月末時点の担当**が負う（[KPI測定仕様書](kpi-measurement-spec.md) §4-2 と同じ判定） |

> **「連絡不通を遂行とみなす」のは、繋がらないことの責任を担当者に負わせないためです。**
> ただし3回の試行記録を必須にすることで、「連絡不通」という記録が逃げ道にならないようにします。

#### 行動指標

```
割引明けフォロー実施率 = フォロー記録のある対象会員数 ÷ 当期の割引明け対象会員数 × 100
```

**目安：95%以上**

> **この指標が少数分母に強い理由：** 対象が3名なら3名全員で100%、30名でも30名全員で100%。
> **分母の大小が到達可能性を変えません。** 産休明け・時短で担当会員が少なくても、満点が取れます。
> 率の指標でありながらダイヤル条項と整合するのは、この性質があるからです。

### 3-2. プラン提案

#### 何をするか

**割引明けフォローの場で、その会員の直近3ヶ月の来店頻度に基づいた具体的なプランを1つ以上提示する。**

#### 遂行したと言える条件

> **カルテに「提示したプラン名」と「提示の根拠（直近の来店回数）」が記録されていること。**

記入例：`フリー→ベーシックを提示。根拠：直近3ヶ月の来店 月2.3回`

#### 提案の中身の基準

[KPI定義集](../kpi/kpi-definitions.md)の「会員1人あたり月間来店回数 目安4回以上」を基準線にします。
来店頻度は継続の最も強い先行指標です。

| 直近3ヶ月の月平均来店 | 提示すべきもの | 提示してはいけないもの |
|---|---|---|
| **4回以上** | 現行プラン継続の確認、または上位プラン | — |
| **2〜3回** | **使い方の提案を先に**（時間帯の変更・予約の取り方・曜日固定） | 値引き。ここは「使えていない」のであって「高い」のではない |
| **2回未満** | **下位プランへの変更を提示し、退会ではなく継続に着地させる** | 現行プランの継続説得（無理があると退会に直行する） |

#### 値引きは担当者の裁量で提示しない（重要）

> **値引き・無料延長・期間延長を、カスタマー担当の判断で提示しません。**
> 必要と判断した場合は、店舗責任者に**上申**します。

マーケティング部の判断原則です。

- **割引で繋いだ会員は継続率が低い。** 割引明け離脱33%という数字そのものが、その証拠です。
  割引明けの離脱を割引で防ぐのは、同じ問題を4ヶ月先送りしているだけです。
- 担当者ごとに値引きの裁量があると、**値引きした人の継続率が高く見え、評価が歪みます。**
- 値引きは価格の変更であり、単価×継続月数で成り立つ事業の根幹に触れます。
  現場の個別判断で動かすものではありません。

**まず改善するのはこの順です：体験の質 → 予約のしやすさ → 初回30日の定着 → 使い方の提案 → 最後に価格。**

#### 禁止表現

プラン提案の場でも、マーケティング部の「やらないこと」がそのまま適用されます。

- **「必ず痩せる」「◯kg減を保証」等の効果保証をしない。**
- 「今だけ」「あと1枠」など、事実でない希少性を作らない。
- 他会員の成果・個人情報を引き合いに出さない。

#### 行動指標

```
プラン提示記録率 = 提示記録のある会員数 ÷ フォロー実施会員数（連絡不通を除く）× 100
```

**目安：90%以上**

### 3-3. カルテ管理

#### 何をするか

**担当会員のカルテを「次に会う人が読んで続きができる」状態に保つ。**

カルテは担当者の備忘録ではなく、**会員との関係の引き継ぎ資産**です。
担当が変わった瞬間に関係がゼロに戻るなら、それは組織の資産になっていません。

#### 遂行したと言える条件（月次チェック）

| # | 条件 |
|---|---|
| a | 担当会員全員に、**直近3ヶ月以内の更新が1件以上**ある（休会中を除く） |
| b | **必須項目が埋まっている**：入会目的／身体の留意事項（医師の指示・既往）／希望時間帯／現行プラン／割引明け月 |
| c | **担当変更時に引き継ぎメモが1件記録されている** |

#### c（引き継ぎメモ）が必須である理由

継続インセンティブの按分は「月末時点の担当登録」で決まります
（[KPI測定仕様書](kpi-measurement-spec.md) §4-2）。
このルールには **「月末直前に担当を付け替えると、その月が丸ごと後任に付く」** という副作用があります。

**引き継ぎメモを必須にすることで、担当変更が記録を伴う行為になり、付け替えの乱用を防ぎます。**
メモの内容は評価しません。**記録があるかどうかだけ**を見ます。

#### 行動指標

```
カルテ更新率 = 直近3ヶ月に更新のある担当会員数 ÷ 担当会員数（休会中を除く）× 100
```

**目安：90%以上**

#### 個人情報の扱い

- カルテ本文は、リポジトリ・社外共有資料・分析用データに転記しません。
- **評価に使うのは「更新されているか」という状態だけです。記載内容は評価対象にしません。**
  内容を採点対象にすると、評価に通るための記述が増え、カルテが業務の役に立たなくなります。

### 3-4. 離脱防止（予兆対応）

#### 何をするか

**離脱の予兆が出た担当会員に、先回りして接触する。**

解約は突然起きません。**来店が落ちてから解約するまでにリードタイムがあります。**
そこに手を打てるかどうかが、防げた解約と防げなかった解約を分けます。

#### 予兆の定義

次のいずれかに該当したら予兆とします。

| # | 条件 | 根拠 |
|---|---|---|
| 1 | **月間来店回数が2回未満の月が2ヶ月連続** | KPI定義集の目安「月4回以上」の**半分**が2ヶ月続いた状態 |
| 2 | 直近1ヶ月の予約キャンセルが**3回以上** | 予約はするが来られていない＝生活との噛み合わせが崩れている |
| 3 | **割引明け月の翌月に来店0回** | 定価移行後の最初の月に来ていない＝価格に納得していない可能性 |

★閾値（2回・2ヶ月・3回）は暫定です。実データ取得後、
「来店が落ちてから解約までのリードタイム」の実測値を見て確定します。

#### 遂行したと言える条件

> **予兆検知の翌月10日までに個別接触を行い、カルテに接触日・手段・反応区分を記録すること。**

#### ⚠ 現在この仕組みは動いていません（重要）

**予兆リストの生成には、会員×月の来店回数データ（[データ請求仕様](data-request-spec.md) T2 の `visit_count`）が必要です。**
このデータは現在未取得です。したがって：

| | |
|---|---|
| 現状 | 予兆リストは作れない。担当者が個人の記憶で気づいたら対応する運用 |
| **評価上の扱い** | **予兆リストが担当者に届いていない期間について、予兆対応の未達を担当者の責めとしない** |
| いつから評価するか | T2 データ取得 → 予兆リストの月次配信が始まった月から |

**リストを配信する責任は顧客管理・CS役割／総務側にあります**（§5）。
仕組みが無いことの責任を、個々の担当者に負わせません。

#### 行動指標（仕組み稼働後）

```
予兆対応率 = 期限内に接触記録のある予兆会員数 ÷ 予兆検知会員数 × 100
```

**目安：85%以上**

## 4. 入会3ヶ月目フォローの標準手順（いつ・誰が・何を）

### 4-1. タイムライン

| タイミング | 誰が | 何を | 記録先 |
|---|---|---|---|
| **入会当日**<br>（体験担当が正社員） | 体験担当（そのままカスタマー担当になる） | ・カスタマー担当として自己紹介する（「これから◯◯さんの担当です」と会員に伝える）<br>・入会目的・希望時間帯・身体の留意事項を聞き取る | **カルテ新規作成**＋Square担当登録 |

| **入会3ヶ月目・15日まで** | カスタマー担当 | ・**個別接触（対面優先）**<br>・継続意向の確認<br>・来店頻度に基づくプラン提示（§3-2） | **カルテ**（接触日・手段・反応区分・提示プラン・根拠） |
| **入会3ヶ月目・25日まで** | カスタマー担当 | ・`不安あり` `連絡不通` の会員について**店舗責任者へ上申**<br>・値引きが必要と判断した場合もここで上申（自己判断で提示しない） | 上申記録 |
| **入会3ヶ月目・月末** | 顧客管理・CS役割 | ・**実施率を集計し、未実施を督促する**<br>・月末時点で未実施の会員がいれば、割引明け月に入る前に手当てする | 月次集計 |
| **入会4ヶ月目（割引明け月）末** | 顧客管理・CS役割 | ・定価移行の結果を確認<br>・**未移行者の理由を記録**（次の設計改善の材料） | 定価移行率の実績 |
| **入会5ヶ月目** | （自動） | ・5ヶ月目突破の判定＝継続インセンティブの支給判定 | Square担当登録に基づき自動 |

### 4-2. なぜ「対面優先」か

会員が最も自然に話せるのは、レッスンの前後です。
わざわざ電話・LINEで「お話があります」と伝えると、それ自体が身構えさせます。
**レッスンに来ている会員には、その場で声をかけるのが最も成功率が高く、本人の負担も小さい。**

ただし、**予兆が出ている会員はレッスンに来ていない**ため、対面の機会がありません。
そこは LINE・電話になります。だから予兆検知の仕組み（§3-4）が要ります。

**担当者に手順だけ渡して動かないのは、たいてい入口の材料が無いからです。**

## 5. 顧客管理・CS役割（役割手当対象）のロール定義書 下敷き

> **カスタマー担当（全正社員の基本職務）と、顧客管理・CS役割（役割手当の対象）は別物です。**
> この区別が曖昧だと「全員がやっていることになぜ手当が付くのか」という問いに答えられません。

| | カスタマー担当 | 顧客管理・CS役割 |
|---|---|---|
| 誰が | **全正社員**（入会時に会員ごとに1名割当） | 店舗で1〜2名（役割認定） |
| 何をする | **自分の担当会員**をフォローする | **仕組みを回す**（リスト配信・割当運用・督促・集計・ルール維持） |
| 報酬 | 基本職務（手当なし）＋継続インセンティブ（成果） | **役割手当**（月額は制度表「役割手当」シート参照）＋基本職務分 |
| 量への依存 | 担当会員数に依存 | **枠数に依存しない**（ダイヤル条項と整合） |

### ロール定義書 素案

#### ロール名
**顧客管理・CS（カスタマーサクセス）**

#### 目的
**入会した会員が5ヶ月目・12ヶ月目を越えて通い続ける状態を、個人の頑張りではなく仕組みで作る。**

#### 責任範囲

| # | 責任 | 具体的な業務 |
|---|---|---|
| 1 | **カスタマー担当の割当運用** | 入会時の担当割当（体験担当が委託の場合）／担当変更の記録確認／欠員時の再割当 |
| 2 | **割引明けリストの配信** | 毎月1〜5日、翌月割引明け会員を担当者別に配信（来店回数を添える） |
| 3 | **未実施の督促** | 月末時点のフォロー未実施を洗い出し、割引明け月に入る前に手当てする |
| 4 | **離脱予兆リストの配信**（仕組み稼働後） | 月次で予兆会員を検知し、担当者別に配信する |
| 5 | **休眠会員の掘り起こし** | 一定期間来店の無い在籍会員・休会者への働きかけ企画 |
| 6 | **カルテ運用ルールの維持** | 必須項目の定義、記録先の統一、更新率のモニタリング |
| 7 | **退会理由の収集と分類** | 退会時の理由コード記録の徹底。**「防げた解約」の抽出**と月次報告 |
| 8 | **口コミ・レビュー対応** | 投稿への返信、低評価への事実確認と改善への接続 |

#### 権限

| できること | できないこと |
|---|---|
| 担当割当・再割当の実行 | **値引き・無料延長の承認**（店舗責任者へ上申する） |
| リスト配信・督促 | 会員の契約内容の変更（本人同意なく） |
| カルテ運用ルールの改定提案 | 他の担当者の評価判定（評価者は一次評価者） |

#### やらないこと

- **レビューの自作自演、対価と引き換えの★評価依頼**（マーケティング部の「やらないこと」）
- 「必ず痩せる」「◯kg減を保証」等の効果保証表現
- 会員の氏名・カルテ内容を、権限のない共有先・リポジトリに転記すること
- 退会の引き止めを目的に、値引きを自己判断で提示すること

#### 成果の見方

> **役割軸で採点するのは、**
> **①〜⑧の業務が回っているか（配信が出たか・督促されたか・分類が溜まったか）です。**
> **定価移行率・解約率そのものは、この役割の採点には使いません**（§1 のルール1）。

| 見るもの | 位置づけ |
|---|---|
| 割引明けリストの配信遅延日数（目標：0日） | **役割軸で採点** |
| フォロー実施率の店舗合計（目標：95%以上） | **役割軸で採点**（仕組みが回っているかの指標） |
| 退会理由の記録率（`R-NA` の比率、目標：10%未満） | **役割軸で採点** |
| 定価移行率（現状67%・目標75%） | 経営指標として監視。**役割軸の採点には使わない** |
| 月次解約率 | 同上 |

#### 必要なスキル・適性

- 会員との長期の信頼関係（創業からの暗黙知を含む）
- 記録を残す習慣と、他者が読める形に整理する力
- 退会の申し出を「責められている」と受け取らずに、事実として分類できること

#### 見直し頻度

**年1回**（制度表「役割手当」シート：ロール定義書は年1回見直し）

#### ★要確定事項

| # | 事項 | 決める人 |
|---|---|---|
| 1 | 役割手当の月額（金額レンジは制度表「役割手当」シート参照。★役員承認前） | 役員／社労士 |
| 2 | 本ロール定義書の確定（導入スケジュール No.6） | 吉村さん |
| 3 | ロール定義書が未整備のまま役割手当を支給する場合、**暫定運用である旨を対象者に説明する**（確認推奨13） | 吉村さん |
| 4 | 記録先システムの統一 | 吉村さん |
| 5 | 上申の様式・宛先 | 吉村さん |

## 6. 評価の当て方

### 6-1. 採点方法

**4領域（§3-1〜3-4）× 各0〜3点＝12点満点。**

| 点 | 基準 |
|---|---|
| **3** | 基準を満たし、**かつ他の担当者に展開した**（やり方を共有した・仕組みに反映させた） |
| **2** | **基準を満たした**（行動指標が目安以上） |
| **1** | 一部実施（行動指標が目安未満だが実施の記録がある） |
| **0** | 未実施（記録が無い） |

### 6-2. 採点の根拠

| 領域 | 行動指標 | 目安 |
|---|---|---|
| 割引明けフォロー | フォロー実施率 | 95%以上 |
| プラン提案 | プラン提示記録率 | 90%以上 |
| カルテ管理 | カルテ更新率 | 90%以上 |
| 離脱防止 | 予兆対応率 | 85%以上（**仕組み稼働後のみ**） |

**面談では、指標の数字に加えて具体例を1件ずつ聞き取り、シートに事実として記載します。**
数字だけだと、記録を作ることが目的化します。

### 6-3. 分母が小さいときの扱い

| 実効分母 | 扱い |
|---|---|
| **3以上** | 率で判定する（分母が小さくても100%到達が可能なため、率が成立する） |
| **3未満** | **率で見ない。実施の有無（定性）で確認する。**「対象2名、2名とも実施」と記載 |
| **0**（対象者なし） | その領域は採点対象外。残りの領域で採点し、その旨を記載 |

> **量軸・質軸の率とは扱いが違います。**
> 質軸の率（5ヶ月目突破率）は、分母が小さいと会員側の事情のばらつきが率を支配するため、
> 実効分母10未満では使えません（[KPI測定仕様書](kpi-measurement-spec.md) §5-2）。
> 行動指標は本人の統制下にあるため、分母3でも「2名中2名に実施した」は意味のある事実です。

### 6-4. ダイヤル条項との整合

| 状況 | 役割軸の扱い |
|---|---|
| 量ダイヤルを下げている（時短等） | **通常どおり評価可能。** 行動基準は枠数に依存しない |
| 担当会員数が少ない | **通常どおり評価可能**（§6-3） |
| 産休・育休で休業中の月 | 当該月は対象期間から除外。休業中にカスタマー担当を持たせない（引き継ぎ必須） |
| 対象期間の全月が休業 | 役割軸も欠測 → 総合評価は**判定保留** |

> 制度表は「役割ダイヤルで貢献を続けられる／顧客管理CSは枠数に依存しない役割として設計済み」
> としています。本書の行動基準は、この設計をそのまま実装したものです。
> **量を下げた人が質・顧客支持の率で実質的に不利になる問題（KPI測定仕様書 §5-1）に対する、
> 具体的な受け皿が本書です。**

### 6-5. 使わないもの（再掲）

- 定価移行率・5ヶ月目突破率・12ヶ月継続率を、役割軸の採点に**使わない**
- カルテの**記載内容の巧拙**を採点に使わない（更新されているかどうかだけを見る）
- 予兆対応を、予兆リストが配信されていない期間について採点に使わない
- 本書の基準を、合意前の過去期間（2026年4〜9月）の採点に使わない（§0）
